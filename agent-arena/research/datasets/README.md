# Historical research datasets

These six files are early case-pack inputs from the research phases of the
Inspektorium audit runtime: four PDF case packs, one JSON case pack and one
JSON pilot pack. Several study-forensics task files and historical run
records name them by their earlier labels, for example "Dataset 5" or
"Dataset 6".

They were moved here and renamed without changing their contents. They are
research material, not part of either installed package; the wheels and the
runtime source distribution do not include this folder. Case packs contain
attributed source references and selected excerpts, which keep the rights of
their sources (see the root [NOTICE](../../../NOTICE)).

The moves and SHA-256 values are listed in the
[research folder index](../README.md).

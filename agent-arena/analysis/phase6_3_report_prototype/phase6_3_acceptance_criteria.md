# Phase 6.3 — Acceptance Criteria & Stop Conditions

Pre-specified acceptance for the claim-forensics report prototype. Each criterion has a
disposition and its evidence.

| id | criterion | disposition | evidence |
|---|---|---|---|
| A-1 | One validated report object produces **both** JSON and Markdown (full + exec) | **MET** | `build_forensic_report` → `canonical_report_bytes` / `render_forensic_report_markdown` / `render_executive_summary` all consume the same object; `test_exec_and_full_share_verdict` |
| A-2 | Report output is **deterministic** | **MET** | sorted-key canonical JSON, digest recomputable, no build-time clock; `test_deterministic_json_and_markdown`, `test_one_char_input_change_changes_digest`; example regenerated byte-for-byte across processes |
| A-3 | All four labels are represented | **MET** | fixtures 01–04; `test_four_labels_present_and_titled` |
| A-4 | Confidence semantics remain frozen (VALID/MISSING/INVALID, no 0.0 coercion) | **MET** | reuses `classify_confidence`; `test_missing_confidence_not_coerced_to_zero`, `test_bool_confidence_rejected_as_invalid`, `test_out_of_range_confidence_is_invalid`, `test_zero_confidence_is_valid_not_missing` |
| A-5 | Missing/invalid values remain explicit | **MET** | MISSING/INVALID/unknown/null preserved; `test_empty_evidence_list_preserved_and_visible`, `test_missing_reader_impact_is_unknown` |
| A-6 | No evidence is invented | **MET** | passthrough only; missing source not filled; `test_missing_source_not_invented` |
| A-7 | `mechanism_vs_evidence` scope stays biologically constrained | **MET** | verdict title + `test_mechanism_vs_evidence_is_biologically_scoped`; failure modes `mechanism_to_human_benefit_leap` / `evidence_tier_mismatch` / `missing_human_evidence` |
| A-8 | Reader-impact risk explicit but not falsely quantified | **MET** | frozen `low/moderate/high/critical/unknown`; `not_a_harm_probability_note`; `risk_vocabulary.md` |
| A-9 | Safer rewrites contain no unsupported new facts | **MET** | numeric-containment guard blocks & drops; `test_rewrite_with_new_number_is_blocked` (fixture 10) |
| A-10 | Provenance visible | **MET** | `provenance.*` incl. input & report digests, parser status, warnings, audit trail |
| A-11 | Parser failures cannot masquerade as successful analyses | **MET** | `parse_ok=false` overrides; `test_parser_failure_status_and_no_verdict`, `test_parser_failure_cannot_masquerade_as_complete` |
| A-12 | All examples are synthetic | **MET** | fixtures marked `synthetic_fixture=true`; synthetic banner; default true when absent |
| A-13 | Leakage checks clean | **MET** | private id/path rejection; `test_private_identifiers_and_paths_rejected`; artifact leakage scan |
| A-14 | Full tests and lint pass | **MET (this session)** | full suite green; ruff clean on changed files |

## Additional frozen guarantees

- Unknown labels rejected (`test_unknown_label_rejected`); unexpected fields rejected
  where frozen (`test_unexpected_*_field_rejected`); label↔title consistency
  (`validate_forensic_report`).
- No hidden threshold or model-selection logic (`test_no_threshold_or_model_selection_logic`).

## Stop conditions (respected)

- No model run; no network; no private/holdout/`internal_only` access.
- No frozen taxonomy/label/gold/status/Phase-5/6.1/6.2/runtime-contract artifact modified.
- Phase 6.4 not begun. No auto-commit; stops for curator review.

# Historical producing-source snapshots

These fourteen source+package-metadata snapshots were read from the private origin
Git object database and hashed individually. They are included for inspecting
historical runtime contracts and provenance, not as the currently installed
package. See `../../publication/2026-10-26/arena-inventory.json` for exact
original commit/blob/file hashes and each purpose. Original Git objects and
private history are not included. A snapshot alone cannot satisfy an original
bundle verifier's private Git commit-existence requirement. Do not use old
live code or historical budgets to launch new work.

The eight earlier P5/P6/P7 producing snapshots and shared asset checks are in
`../../publication/2026-10-26/additional-historical-snapshots.json`. The early
P5A 150-response manifest has no recorded code ID; no producer is invented.

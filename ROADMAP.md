# Roadmap

The v0.1 boundary is frozen in [SCOPE.md](SCOPE.md). This file is parking space
for possible independent exploration, not authorization or a release promise.

Possible post-v0.1 questions include:

- additional provider adapters;
- richer explicitly supplied source formats;
- alternate public relationship vocabularies;
- improved trace inspection for deterministic guard decisions;
- optional local interfaces over the same small kernel.

Any proposal should preserve the distinction between evaluator-generated
semantic judgments and deterministic textual validation. Scores, benchmarks,
agent orchestration, and production governance systems are not implied by this
list.
